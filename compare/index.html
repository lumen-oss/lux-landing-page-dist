Notes

  1. Custom build backends in Lux go through a compatibility layer that uses Luarocks as a backend.
  2. Lux aims to be compatible with the Luarocks version parser, which allows arbitrary components. Anything after the third component (except the specrev) is treated as a prerelease/build version, and versions with and without prerelease components can still be compared.
  3. You Aren't Gonna Need It. CVS, Mercurial, SVN, and SSCM sources are intentionally out of scope.
  4. Sandbox build execution is opt-in via the [build.runner] config.
